# Task-02: Number Guessing Game

## Description
This project is a simple Number Guessing Game built using Python. The program generates a random number between 1 and 100. The user keeps guessing until the correct number is found. It also provides hints whether the guess is too high or too low and displays the total number of attempts.

## Features
- Random number generation
- Too High / Too Low hints
- Counts total attempts
- User-friendly console interaction

## Technologies Used
- Python

## How to Run
1. Open the project in VS Code.
2. Run:
   python guessing_game.py
